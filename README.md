# UniCircle

UniCircle is Pointfex's campus marketplace for verified university members to buy, sell, rent, exchange, donate, and lend items for free.

## Run the frontend

Use Node.js 20.19+ or 22.12+.

```sh
cd frontend
npm ci
npm run dev
```

Open the local URL printed by Vite and choose **Try demo account**. The React demo stores activity in the browser.
